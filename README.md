# For Users - ユーザー向け

ここでは"ゲーム『剣と魔法のログレス -いにしえの女神-』"を"ゲーム本作"と呼びます。

## おことわり

- このウェブアプリは多言語対応を現時点で想定しません。<br>
  - 【背景】<br>
  ゲーム本作には日本語版のみであり、各用語も日本語表記しか存在しません。(※とうの昔には英語版もリリースされていましたがサービスを終了しました。)<br>
  実態として英語圏のユーザーも中国語圏のユーザーもゲーム本作唯一の日本語版で遊んでおり、誰もがゲーム体験の全てにおいて日本語表記です。
- ゲーム本作の表記をなるべく踏襲しています。ただし表記揺れが激しいものや誤解を招きやすいものに対しては、一部の有志コミュニティで使われる表記/表現に調整しています。
